# ForgeX NightCruise v7.1 Open Source Preview

This is the first open-source-ready preview release of ForgeX NightCruise.

这是 ForgeX NightCruise 的第一个开源准备版。

Highlights:

- Synthetic dataset factory for local AI training
- Real-time CPU/RAM/GPU observation window
- Ollama, OpenAI-compatible API, llama.cpp server, GGUF, and HuggingFace backends
- Strict bilingual anti-hallucination dataset prompt
- JSONL/JSON/TXT export
- Fresh session optimization for long batch jobs

亮点：

- 面向本地 AI 训练的合成数据集工厂
- 实时 CPU/RAM/GPU 观测窗
- 支持 Ollama、OpenAI-compatible API、llama.cpp server、GGUF、HuggingFace 后端
- 严格中英双语反幻觉数据集提示词
- 支持 JSONL/JSON/TXT 导出
- 面向长批处理任务的全新会话优化
