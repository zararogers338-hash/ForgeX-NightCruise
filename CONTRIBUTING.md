# Contributing / 贡献指南

Contributions are welcome.

欢迎贡献。

Good first contributions:

- Improve bilingual documentation / 改进中英双语文档
- Add screenshots / 添加截图
- Add dataset examples / 添加数据集样例
- Improve backend compatibility / 改进后端兼容性
- Add output format converters / 添加导出格式转换器
- Improve hallucination checks / 改进幻觉检查

Please avoid committing private data, API keys, large models, generated datasets, or `.pyc` files.

请不要提交隐私数据、API Key、大模型文件、生成数据集或 `.pyc` 文件。
