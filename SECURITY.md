# Security Policy / 安全政策

## Supported version / 支持版本

The open-source preview version is maintained on a best-effort basis.

开源预览版以尽力维护为主。

## Reporting security issues / 报告安全问题

Please open a GitHub issue if you find a security problem that does not expose private secrets. If the problem involves secrets, private data, or exploitable details, avoid posting sensitive material publicly.

如果发现安全问题，可以提交 GitHub Issue；如果涉及密钥、隐私数据或可利用细节，请不要公开粘贴敏感内容。

## Important reminders / 重要提醒

- Do not commit API keys.
- Do not upload private documents to third-party APIs.
- Only load models from trusted sources.
- Monitor hardware temperatures during long local inference jobs.

- 不要提交 API Key。
- 不要把隐私文档上传到第三方 API。
- 只加载可信来源模型。
- 长时间本地推理时注意硬件温度。
